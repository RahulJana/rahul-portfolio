# Rahul Jana - Developer Portfolio

Professional portfolio website showcasing AI/ML expertise, projects, and achievements.

## 🌟 Features

- **Responsive Design**: Mobile-first approach for optimal viewing on all devices
- **Modern UI/UX**: Clean, professional design with smooth animations and transitions
- **AI/ML Focused**: Tailored content highlighting machine learning and cloud computing expertise
- **Performance Optimized**: Lightweight CSS with minimal dependencies, lazy-loaded images
- **SEO Friendly**: Structured data (JSON-LD), meta tags, and semantic HTML
- **Accessibility**: WCAG compliance with proper color contrast and ARIA labels

## 📁 Structure

- `index.html` - Main portfolio homepage with navigation, about, experience, and skills
- `achievements.html` - Awards, recognition, and professional achievements
- `github.html` - Featured projects and open-source contributions
- `profile.jpg` - Professional profile photo
- `Rahul_s_Resume_2025.pdf` - Professional resume
